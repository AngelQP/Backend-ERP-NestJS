# Base de Proyecto NestJs con Postgres

1. Clonar proyecto
2. ``` yarn install```
3. Clonar el archivo ```.env.template``` y renombrarlo a ```.env```
4. Cambiar las variables de entorno
5. Levantar la base de datos puede ser docker, base de dato local, etc

6. Levantar el backend: ```yarn start:dev```
